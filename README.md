## 用之前要知道的四条限制

**流量跑完不停机，限速到共享 10Mbps。** 这一点全系通用，比很多“超出即停机”的商家友好。10Mbps 大概还能维持网页浏览、文字聊天和低码率音频，看 1080p 就别想了。想恢复满速可以手动重置流量，费用在 ¥7 到 ¥10 之间，不同套餐不一样，番茄特供有帖子标的是 ¥10。

**不保证大陆直连。** 官方定位是国际互联出口，不是专线回国产品。日本节点移动走 CMI 直连，电信联通绕美；香港节点接的是国际带宽。高峰期延迟会往上走，跑国内业务、连数据库这类用途不要考虑。

**解锁是 DNS 层面，不是原生 IP。** 机器本身的 IP 属于机房段，靠内置的 AKILE DNS 完成对应地区的流媒体解锁。这意味着它不会给你一个“看起来像香港居民家宽”的 IP，做跨境电商账号、需要 IP 纯净度的场景要另找原生 IP 产品线。

**入门盘小。** 5GB 到 10GB 是装完系统就紧张的容量。缓存视频、跑日志、放静态资源，很快会见底。

有测评提到，1Gbps 档位的套餐实测能跑到 900Mbps 到 1Gbps，机器开通通常在几分钟内完成。这些是第三方转述的社区反馈，不是本文的实测数据，当参考看。
